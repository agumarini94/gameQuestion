🎮 TechLevel – Gamified Learning Platform

TechLevel is a web-based educational quiz game designed to help users study and practice programming concepts through a level-based progression system.

The application combines learning, gamification, and competition, allowing users to advance through levels represented by characters while reinforcing technical knowledge.

This project is built as a full-stack practice application, focused on clean architecture, real business logic, and scalability.

⸻

🚀 Features

✅ Authentication (MVP)
	•	User registration and login
	•	Persistent progress per user

🧠 Level-Based Quiz System
	•	Questions organized by:
	•	topic
	•	difficulty
	•	level
	•	Correct answers:
	•	add progress
	•	unlock next questions
	•	Incorrect answers:
	•	do not subtract points
	•	user remains at the same level until mastery

🎭 Character Progression
	•	Each level is represented by a character
	•	Users choose a character theme:
	•	Pokémon
	•	Dragon Ball
	•	Football
	•	Cars
	•	Characters evolve as levels increase

📊 Progress Tracking
	•	Current level
	•	Progress bar
	•	Ranking between users

⚔️ Duels (Planned)
	•	1 vs 1 competitive mode
	•	Same-level questions
	•	Winner advances, loser may lose levels
